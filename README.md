# 🇩🇿 Dialects AI Foundry: Algerian Multi-Dialect Speech Dataset

مستودع بيانات صوتية مفتوح المصدر ومفرغ يدويا للدارجة الجزائرية، موجه لتدريب وضبط نماذج التعرف الآلي على الكلام (ASR).

---

## 📌 المواصفات الفنية للبيانات

- **إجمالي العينات الصالحة:** 234 عينة صوتية مفرغة يدويا ومراجعة.
- **التغطية الجغرافية:** 6 ولايات ممثلة للأقطاب الأربعة (الغرب، الشرق، الوسط، الجنوب، والهضاب العليا).
- **مواصفات الصوت:** Mono, 16000 Hz, 16-bit PCM WAV.
- **تقسيم البيانات (Stratified Split):**
  - **التدريب (Train):** 199 عينة (85.0%)
  - **التحقق (Validation):** 35 عينة (15.0%)
- **حجم معجم الرموز (Vocabulary):** 34 رمزا موحدا.

## 📁 هيكل المشروع

- **dataset/audio/**: ملفات الصوت بصيغة WAV (16kHz).
- **dataset/manifest.jsonl**: السجل الشامل لجميع العينات.
- **dataset/train.jsonl**: عينات التدريب المقسمة.
- **dataset/val.jsonl**: عينات التقييم المقسمة.
- **dataset/vocab.json**: معجم الرموز المستخرجة.
- **split_audio.py**: التقطيع الآلي بحسب فترات الصمت.
- **transcribe.py**: واجهة سطر الأوامر لتفريغ العينات يدويا.
- **inspect_dataset.py**: فحص الجودة وتوزيع الإحصائيات.
- **prepare_splits.py**: معالجة النصوص وتقسيم البيانات.

---

## 🛠️ كيفية الاستخدام

1. **فحص جودة البيانات وتوزيعها:**
   python inspect_dataset.py

2. **إعادة معالجة النصوص وتحديث التقسيم:**
   python prepare_splits.py
