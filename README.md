# Dialects AI Foundry 🇩🇿

منصة برمجية لجمع، معالجة، وتفريغ التسجيلات الصوتية للهجات الجزائرية المحلية، وتجهيز مجموعات البيانات لتدريب نماذج الذكاء الاصطناعي (مثل Whisper).

## 📁 هيكل المشروع

- `data/wav/`: مجلد التسجيلات الصوتية بصيغة WAV.
- `metadata/`: ملفات الفهرسة والتفريغ النصي (`dataset.csv`, `dataset.jsonl`).
- `collector.py`: أداة تسجيل وتنظيم العينات الصوتية.
- `annotate.py`: سكربت مراجعة وتعديل التفريغ النصي والمعلومات الوصفية.
- `stats_export.py`: استخراج إحصائيات حول مدة التسجيلات وتوزيع اللهجات.

## 🚀 الاستخدام

1. إضافة العينات الصوتية إلى مسار `data/wav/`.
2. تشغيل سكربت التفريغ وتحديث البيانات الوصفية.
3. تصدير التقارير الإحصائية.
